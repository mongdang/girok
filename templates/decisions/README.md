## 작성 규칙

- **ID 형식**: {adrIdRule}
- **새 결정이 생기면**: 파일을 만들고, 위 표에 한 줄 추가하고, 현황판 일자별 로그에 ID 를
  인용한다. 병행 기간에는 자기 `docs_<id>/decisions/` 에 만들고 그 폴더 인덱스에 등재
- **판단을 뒤집으면**: 기존 ADR 의 **상태만** `superseded-by-<새 ID>` 로 바꾸고 본문은
  고치지 않는다. 왜 틀렸는지는 새 ADR 에 적는다
- **형식**: `.method/RULES.md` 의 ADR 카드 구조 참고. 개별 ADR 에는 `## 목차` 를 두지 않는다
